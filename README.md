# Data Guns SQL 🎸📊

Proyecto de análisis de datos musicales de Guns N' Roses usando Python, Pandas, MySQL y SQL.

## Objetivo

Practicar un flujo básico de datos:

Spotify API → CSV → Pandas → MySQL → Consultas SQL

## Tecnologías usadas

- Python
- Pandas
- MySQL
- SQL
- SQLAlchemy
- PyMySQL
- Spotify API

## Análisis realizados

- Cantidad total de canciones
- Cantidad de canciones por álbum
- Duración promedio por álbum
- Top 10 canciones más largas
