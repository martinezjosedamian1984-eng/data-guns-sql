# Data Guns SQL 🎸📊

Proyecto de análisis de datos musicales de Guns N' Roses usando Python, Pandas, MySQL y SQL.

## Objetivo

Practicar un flujo básico de datos:

Spotify API → CSV → Pandas → MySQL → Consultas SQL

## Tecnologías usadas

- Python
- Pandas
- MySQL
- SQL
- SQLAlchemy
- PyMySQL
- Spotify API

## Análisis realizados

- Cantidad total de canciones
- Cantidad de canciones por álbum
- Duración promedio por álbum
- Top 10 canciones más largas

## Importante sobre el dataset

El archivo `guns_n_roses_spotify_dataset.csv` no está incluido en el repositorio por buenas prácticas.

Para ejecutar el proyecto, cada usuario debe generar localmente su propio CSV usando credenciales propias de Spotify Developer.

Este proyecto es educativo y no está afiliado ni respaldado por Spotify ni por Guns N' Roses.
